# درنلا — فروشگاه اینترنتی پوشاک دخترانه

- **سایت:** Next.js 14 + Tailwind، راست‌چین با فونت ایران‌سنس X و طراحی صورتی
- **API:** NestJS 10 + Prisma + PostgreSQL
- **سرور:** Docker Compose + nginx + SSL رایگان Let's Encrypt — راهنمای کامل در [deploy/README.md](deploy/README.md)

## متن‌های سایت

همه متن‌های بخش فروشگاه در `apps/web/src/dictionary/fa.ts` و متن صفحه‌های ثابت (درباره ما، سؤال‌ها، قوانین) در `apps/web/src/dictionary/pages.ts` است.

## اجرا روی سیستم خودتان

```bash
docker compose -f docker-compose.dev.yml up -d
```

```bash
cd apps/api && cp .env.example .env && npm install && npx prisma migrate deploy && npm run build && npm run db:seed && npm run dev
```

```bash
cd apps/web && cp .env.example .env.local && npm install && npm run dev
```

در حالت توسعه (`SMS_PROVIDER=console`) کد ورود روی صفحه نشان داده می‌شود.

## تغییر مدل پایگاه داده

بعد از ویرایش `apps/api/prisma/schema.prisma`:

```bash
cd apps/api && npx prisma migrate dev --name توضیح-تغییر
```

روی سرور خودکار اعمال می‌شود.
